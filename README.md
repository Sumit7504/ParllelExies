# ParllelExies - Parallax Scrolling Effect

This project demonstrates a parallax scrolling effect using HTML and CSS. It features a visually appealing design with layered backgrounds and sections describing various activities.

## Features

- **Parallax Scrolling**: Smooth scrolling effect with layered backgrounds.
- **Responsive Design**: Works seamlessly on different screen sizes.
- **Informative Sections**: Includes sections on Coffee Time, Bicycle Racing, Paragliding, and Surfing.

## Project Structure

- **`parllelExc.html`**: The main HTML file that structures the webpage and includes the content.
- **`sty.css`**: The CSS file that styles the webpage and implements the parallax effect.
